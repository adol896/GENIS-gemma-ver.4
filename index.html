📖 使い方 ＆ VOICEVOX 起動手順マニュアル

1. GitHub Pages 経由で動作させる場合（推奨設定）

GitHub Pages などの外部 Web サイト（https://）からローカルの VOICEVOX（http://localhost:50021）へ通信するため、CORS 制限許可フラグを付与して起動します。

  • ショートカット起動（おすすめ）: VOICEVOX インストール先の vv-engine フォルダ内にある run.exe（または voicevox_engine.exe）のショートカットを作成し、右クリック ➔ 「プロパティ」を開きます。「リンク先」の末尾に半角スペースを入れて --cors_policy_mode all を追記して起動します。
  • コマンドプロンプト起動: 該当フォルダでターミナルを開き、run.exe --cors_policy_mode all を直接実行します。

2. OBS ブラウザソースで読み込む場合（ローカル起動）

  • OBS のソース追加で「ブラウザ」を選択し、「ローカルファイル」 にチェックを入れて PC 内の index.html を直接読み込ませます。（※ローカル起動の場合は CORS 許可オプションなしでも機能します）

3. 基本操作 ＆ 音声コマンド一覧

  • 初期起動・アンロック: 画面を 1 回クリックしてブラウザの音声制限を解除します。
  • 会話の再開: 「話そうぜ」「喋ってくれ」「再開」「いいよ」など
  • 一時停止 (MUTED): 「静かにして」「黙って」「喋るのやめて」など
  • Wikipedia 検索機能: 「〇〇について調べて」「〇〇を調べて」と発声
  • スパチャ演出: 「スパチャ」「スーパーチャット」「感謝」など
  • カットイン演出: 「ここだ」「ここで決める」など
